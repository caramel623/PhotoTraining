Taiwan license plate detector model

Training dataset: Taiwan License Plate Recognition Research (TLPRR)

The bundled ONNX weights were trained by this project from version 7 of the
dataset. The model is used only to locate license plate regions; OCR remains a
separate step with mandatory human review.

Modification status:
The bundled models/taiwan_plate_detector.onnx is not an unchanged upstream
model file. This project trained and exported the ONNX weights using version 7
of the TLPRR material, so the weights are a modified / derived artifact.
